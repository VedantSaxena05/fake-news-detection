# Fake News Detection using NLP

A machine learning project that detects fake news articles using NLP techniques, TF-IDF vectorization, and Logistic Regression.

## Features
- Text preprocessing
- TF-IDF vectorization
- Fake vs Real news classification
- Linguistic feature extraction

## Tech Stack
- Python
- Pandas
- NLTK
- Scikit-learn

## Accuracy
~98% accuracy achieved.
